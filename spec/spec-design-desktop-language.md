# 背景与目标

用户可选择简体中文或英文，并在游戏切换与下次打开应用时沿用。

## 1. 范围与非目标

窗口导航、页面和操作提示使用中英资源。Steam 作者标题和描述、用户命名、原始日志与系统错误细节保持其来源文本。

## 2. 需求与验收条件

| ID | 给定 | 当 | 则 |
| --- | --- | --- | --- |
| AC-01 | 新安装或旧设置 | 启动 | 默认简体中文，可切换到英文 |
| AC-02 | 已编辑未保存的配置 | 切换界面语言 | 文案更新，原配置和草稿可继续编辑 |
| AC-03 | 已保存语言 | 切换游戏或重启 | 仍使用所选语言 |
| AC-04 | 本机持久化失败、未知语言或缺失资源 | 加载或切换 | 保留可用语言并使用中性资源回退 |

## 3. 责任模块与实现步骤

Core 使用 .resx 管理可本地化应用消息。Desktop 复用动态资源和数据绑定刷新。Infrastructure 原子存储一个应用级偏好文件，与各游戏路径设置隔离。

## 4. 契约、依赖与兼容性

保留原游戏设置、配置格式和外部内容。英文布局沿用已有页面，可读性单独验证。

## 5. 测试策略

验证资源完整性、运行时切换、偏好读写、草稿保留和最小窗口渲染。

## 6. 审查与执行结果

- 已在路径设置接入语言切换，保存到应用数据根目录的 `ui-language.json`。中英文各有 764 条资源。新生成的常见操作和错误消息跟随当前语言，已保存的任务历史和来源内容保留原文。
- macOS arm64 上验证了语言热切换、配置草稿、工坊筛选、其他游戏工作区、未知偏好和写入失败。1000 × 690 的设置、配置和诊断页已渲染复核。
- Release 还原、构建、627 项全量测试与差异检查通过。截图与测试证据在 `artifacts/language-diagnostics/`。
