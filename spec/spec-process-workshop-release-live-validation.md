# 背景与目标

已有离线探针覆盖本地历史、搜索处理和缓存分配。补测待发布 macOS arm64 Release 通过真实 Steam 搜索和下载的速度，并将四项已知问题转成可复现的回归计划。报告分别标注安装版、当前候选版、离线夹具和真实 Steam 样本。

## 1. 四项回归计划

| 编号 | 夹具和操作 | 通过标准 |
| --- | --- | --- |
| 1 多游戏历史隔离 | CK3 写入 120 条较新任务，Victoria 3 写入 105 条较旧任务，混用旧文件和新格式。分别打开工作区、重启并倒序切换。补测一个游戏历史为空和双工作区并行加载。 | 各游戏按自己的更新时间取最近 100 条，包含同游戏新旧格式，跨游戏任务不计入限额。保持 CK3 和 Victoria 3 旧记录原路径可读。 |
| 2 过期任务重新检查 | 完成 Mod A，完成另外 101 项将 A 淘汰，重启后从工坊再次检查 A。两窗口并发提交相同游戏和 ID，另用不同游戏的相同 ID 验证隔离。覆盖 A 已安装、待更新、上次失败和已主动移除记录四种状态。 | 已有记录可定位时复用原历史身份，磁盘最多留一条对应 Steam 任务。已有安装无需更新时传输 0 字节，待更新只发起一次跟踪。主动移除后重新发起可建立新身份。 |
| 3 删除失败和恢复 | 故障注入模拟目标记录不可删除、文件占用、部分重复记录已删、跨实例锁冲突。通过下载页移除，观察错误后重启，再解除故障重试。另测独立物品并行删除。 | 未完成的删除明确失败，界面保持可重试状态。重试后目标记录全部消失且重启不复现。其他游戏历史、Steam 订阅和已安装文件保留。 |
| 4 搜索缓存开销和旧历史冷读 | 每页固定 30 条，分别准备 0、15、30 个已读详情，记录热命中、过期回填和强制刷新时详情读取、文件 I/O、回源次数、P50/P95 与分配。混合更早、相同和更新修订，加并行查阅、取消、失效和损坏。另以 5,000 条旧历史测首次及二次读。 | 保持结果和修订语义，热命中无 Steam 请求，相同修订零详情写入。若减少逐条检查，需报告实际读取次数下降并保留跨实例一致性。旧历史首次取最近 100 条且在后台运行，耗时作为回归基线。 |

前两项当前已有替身复现，第三项以代码发现为起点，第四项已有本地基线。上表通过标准用于对应修复后的验收，真实服务测速单独记录。

## 2. 上线候选真实测速

| 编号 | 操作 | 记录与判定 |
| --- | --- | --- |
| LIVE-01 工坊搜索 | 在隔离数据目录运行候选 Release，使用 Steam 公共工坊首页、常用英文关键词和中文关键词。测未缓存查询、同查询热命中、强制刷新。 | 记录首次结果、整个搜索、是否回源、HTTP 状态、条数和 P50/P95。网络冷命中与本地热命中分别统计，保留超时和空结果。桌面首屏如使用无窗口 Avalonia 探针，注明不含 macOS 屏幕合成。 |
| LIVE-02 Steam 新下载 | 使用已登录的本机 Steam 和项目发布入口，选用预先核对为未安装、未订阅的公开 CK3 Mod。独立存放任务历史。记录包大小和下载前后状态。 | 只有 Steam 字节或同一时间段 Steam 日志确认有实际传输，且完成后安装内容可读，才算新下载成功。记录命令入口到终态、开始到首字节、传输阶段、实际网络字节和安装大小。采样不足以得到可信速率时只报告单次耗时。 |
| LIVE-03 已安装复查 | 对 LIVE-02 刚完成的同一工坊项再次检查。需要时同时提交两个跟踪请求，观察订阅、路径和字节。 | 单独统计复查耗时。已安装且无更新时复用 Steam 目录和可见历史身份，不将 0 字节复查计入下载速率。 |

真实下载限于 CK3 工坊 Mod。测试使用已有游戏安装和 Steam 登录会话。只使用测试新增的订阅和内容进行清理，记录清理是否成功。下载任务写到独立数据目录。公开搜索与真实下载按不同时间段采样。当前候选测试只创建本地 Release 产物。

## 3. 证据

记录构建方式和关键二进制 SHA-256、macOS 版本、游戏、测试工坊 ID、采样时间、结果和未验证原因。完整性能日志留在本机，汇总中省略账户和个人路径。样本为单机当时网络观测。

## 4. 执行结果

- LIVE-01 已完成。待发布版和本机安装版共 54 次真实查询均成功。候选冷查询、热命中、强制刷新 P50 分别为 1.28 秒、6.47 ms、1.21 秒。
- LIVE-02 已完成。两个未安装的 CK3 工坊 Mod 分别耗时 31.96 秒和 21.05 秒，实际字节增长，Steam 确认完成并通过安装文件校验。
- LIVE-03 已完成。分别耗时 0.41 秒和 0.36 秒，均传输 0 B 并复用身份。测试新增订阅已撤销，目录清理已确认。
- 四项回归中，前 3 项在候选程序集上复现，第四项已测真实回源和热命中，并保留原有本地逐条检查基线。故障矩阵其余组合待测。
- Release 全量回归 581 项通过。具体速度、终态进度异常、环境和证据见[真实测速报告](../docs/workshop-release-live-test-report.md)。
