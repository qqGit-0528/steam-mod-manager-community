# 目标与验收

用兼容性短标签替换下载卡片上的工坊 ID。依据当前游戏版本和当前安装的版本声明，复用绿色「兼容」、红色「不兼容」与灰色「未知」。已有任务和历史仍按原工坊 ID 关联。若当前安装没有可用的声明，可使用该任务已知的工坊标签。无需额外联网请求。

## 测试与结果

- 无窗口界面回归核对原工坊 ID 文本消失，绿色 `#2F9E6E` 和红色 `#D9453A` 分别对应「兼容」和「不兼容」。
- 临时安装在同一路径更新版本声明后，卡片采用本地声明，即使下载任务已知的工坊标签仍匹配。
- macOS arm64 Release 构建和完整测试通过，共 575 项。已查看下载卡片渲染。
- 本机安装的旧版仍显示工坊 ID。用同一源码重新打包、备份旧版并更新安装后，在实际下载页核对「Sibling Marriage」显示「兼容」。绿色和红色的界面专项回归重新执行通过。
