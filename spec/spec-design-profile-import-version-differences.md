# 背景与目标

第二批扩展运行配置的诊断和导入预览。

## 1. 范围与非目标

保留原清单的声明版本，展示本机候选并明确处理版本差异。兼容无版本字段的旧清单。

## 2. 需求与验收条件

唯一同版本候选可自动选中。异版或版本未知的候选需要明确采用，否则保留待匹配项。多个候选展示路径与版本。扫描或下载后只自动匹配符合预期的版本。确认前重扫核对选定副本。

## 3. 责任模块与实现步骤

沿用 JSON 格式、安装 ID 和配置存储。待匹配项以原有空路径及原清单版本表示，无迁移。确认采用本机副本时才记录该副本版本。

## 4. 契约、依赖与兼容性

兼容现有配置与调用方。操作绑定当前游戏工作区。

## 5. 测试策略

覆盖正向流程、数据变化、缺失、解析或请求失败及取消。按 [协作规范](../CONTRIBUTING.md#4-必须完成的检查) 执行门禁。

## 6. 审查与执行结果

自动化覆盖旧清单、唯一同版本副本、异版或未声明版本、多个候选和下载后迟到匹配。桌面用例验证明确选择本机版本后重新扫描，发现副本已更新则要求再次核对。真实绑定控件选择新版本后保存，顺序与启停继续走原有用例。导入预览核对 Mod 版本声明，便携清单格式保持兼容。

macOS arm64 还原、Release 构建、全量 603 项测试及 `git diff --check` 通过。截图、探针日志和 TRX 位于本地 `artifacts/batch2/`。
