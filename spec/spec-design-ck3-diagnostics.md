# 背景与目标

玩家可在当前 CK3 工作区查看崩溃文件和会话日志的相关线索。

## 1. 范围与非目标

按需读取 CK3 用户数据目录。区分 logs 下的最近会话和 crashes 下的历史报告。显示文件路径、修改时间和尾部内容。保留日志原文，自动归因另行验证。

## 2. 需求与验收条件

| ID | 给定 | 当 | 则 |
| --- | --- | --- | --- |
| AC-01 | 有会话日志及多个历史报告 | 点击读取 | 分组呈现，最新报告在前，可打开目录 |
| AC-02 | 目录为空、文件巨大、损坏、不可读或为链接 | 读取 | 保留其他有效结果，标记空、截断或读取问题 |
| AC-03 | 读取尚未完成 | 取消、离开页面或切换游戏 | 不呈现过期结果，读取路径保持在发起时的工作区 |

## 3. 责任模块与实现步骤

WorkspaceService 复用游戏目录发现。Infrastructure 按固定文件名和资源上限读取。Desktop 绑定报告并通过现有导航端口打开目录。

## 4. 契约、依赖与兼容性

仅 CK3 注册读取端口。读取最多 5 个最近崩溃报告，每文件最多 32 KiB、120 行。日志只读且不上传。

## 5. 测试策略

使用隔离日志及合成崩溃报告测试排序、限制、失效、权限和入口。复用真实隔离 CK3 会话输出验证格式。

## 6. 审查与执行结果

- CK3 侧栏诊断入口已接入。支持会话和报告中的错误、游戏、系统、初始化、调试、界面警告和数据库冲突日志，以及报告目录中的异常文本、元数据和堆栈。
- 测试覆盖近期报告排序、截断、空目录、编码、链接、取消、工作区切换和打开所选目录。使用合成历史报告验证展示。复用隔离 CK3 1.20.0.4 的真实会话读到 7 个日志文件，调试和初始化日志各截断至 120 行。已确认无 CK3 进程。
- macOS arm64 Release 还原、构建、627 项全量测试与差异检查通过。证据在 `artifacts/language-diagnostics/`。
