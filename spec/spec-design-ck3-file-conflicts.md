# 背景与目标

用户能找出启用的 Mod 提供了哪些同路径文件，并据配置顺序排查覆盖。

## 1. 范围与非目标

CK3 当前配置草稿的启用项。读取当前安装目录或 ZIP，不解压到磁盘。比较同一相对路径的文件内容。定义、目录替换和自动修复由独立规格处理。

## 2. 需求与验收条件

| ID | 给定 | 当 | 则 |
| --- | --- | --- | --- |
| AC-01 | 两个或更多启用的安装提供相同相对路径 | 点击检查文件冲突 | 按配置顺序显示参与项，区分内容相同、不同和无法比较 |
| AC-02 | 禁用、缺失、无法读取、越界 ZIP 路径或链接 | 检查配置 | 禁用项不参与，其他情况明确报告，仍检查剩余可用安装 |
| AC-03 | 检查进行中或已有报告 | 取消、修改顺序或启停、切换配置或游戏 | 旧结果不会写入当前上下文 |
| AC-04 | 隔离 CK3 可用 | 对同一文件的两个 Mod 交换加载顺序并进入游戏 | 记录配置顺序和实机效果，仅在已验证的语义范围显示预计覆盖项 |

## 3. 责任模块与实现步骤

Core 提供只读检查端口和报告。WorkspaceService 复用发现与扫描，按安装 ID 解析启用项。Infrastructure 在后台索引精确相对路径，仅比较碰撞路径的文件。Desktop 显示当前配置检查结果，配置或安装变化时清除结果。无配置或游戏写入。

## 4. 契约、依赖与兼容性

可选端口仅在 CK3 工作区启用。采用区分大小写的相对路径，不含根目录描述和常见打包元数据。保留原配置、已保存旧版及 ZIP 安装格式。

## 5. 测试策略

临时目录与 ZIP 验证同路径和顺序、同大小不同内容、重复 ZIP 条目、文件读取失败和取消。桌面检查正常入口及过期结果。若有实机，使用隔离用户目录与可见的测试覆盖。门禁见 [协作规范](../CONTRIBUTING.md#4-必须完成的检查)。

## 6. 审查与执行结果

AC-01 至 AC-04 通过。覆盖目录与 ZIP、同大小异内容、完全相同、禁用项、缺失安装、越界或重复 ZIP 条目、符号链接、取消和切换工作区。每次检查最多索引 50 万个文件，等大小的碰撞文件按内容比较时单文件上限为 1 GiB，超过上限报告无法比较。

隔离 CK3 1.20.0.4 两轮均进入主菜单。相同路径 `gui/frontend_main.gui` 在 A→B 时只记录 B 的探针标记，在 B→A 时只记录 A 的标记。探针仅位于测试文件，利用 GUI 解析日志识别被读取的副本。生产 WorkspaceService 也在同一夹具上报告了该相对路径、内容不同和正确顺序。此证据针对该主菜单文件，界面提示可能覆盖并显示配置顺序。测试游戏进程已退出。

macOS arm64 执行解决方案还原、Release 构建、595 项全量测试及 `git diff --check`。无窗口截图和测试报告保存在本地 `artifacts/batch1/`。
