# 背景与目标

文件监听和桌面按安装 ID 与可用性过滤扫描，同路径更新会丢掉元数据变化。下载任务历史还被用来表示当前安装，删除后容易显示过期结果。

## 1. 范围与非目标

覆盖本地库扫描更新、下载完成和删除触发的刷新，以及下载页对当前安装状态的展示。Steam 下载、订阅、删除权限和历史 JSON 沿用现有契约。工坊来源归类与配置用例拆分属于独立改动。

## 2. 需求与验收条件

| ID | 给定 | 当 | 则 |
| --- | --- | --- | --- |
| AC-01 | Mod 的安装 ID 和可用性保持不变 | 同路径更新描述文件 | 已安装列表刷新名称、版本及兼容信息。同内容重复扫描保留现有行与选择。 |
| AC-02 | 文件监听、下载完成与删除都可产生扫描 | 扫描先后完成或部分目录告警 | 本地库统一接收和比较，旧扫描不覆盖更新结果，部分告警保留未确认的安装，明确删除的条目除外。下载刷新独立于配置文件读取。 |
| AC-03 | 下载历史已完成 | 同一安装被删除、从历史重新载入或重新下载 | 历史保留「下载完成」。另显示当前安装状态，只有核对到有效安装路径才启用打开目录。另一份同工坊副本不冒充本次安装。 |
| AC-04 | Steam 下载为监狱建筑师旧版 UGC 容器 | 本地扫描不列出该容器 | 仅在当前游戏已发现的工坊目录内核对该任务记录的内容路径。 |

## 3. 责任模块与实施

Application 的本地库保存已接收扫描并核对当前安装。文件监听仍负责文件事件合并和产生扫描，下载及删除触发刷新。Desktop 只投影列表和下载卡片。Infrastructure 核对磁盘路径与旧版容器。

## 4. 契约与兼容性

扫描顺序只在进程内使用，现有下载历史和配置格式继续沿用。历史没有可核对路径时展示未确认。

## 5. 测试策略

复用监听、本地通知和下载界面测试。补充同路径更新、过期扫描、删除后下载历史和旧版内容边界的验收。

## 6. 审查与执行结果

- AC-01 由文件监听和桌面本地库测试覆盖，同路径版本、名称和兼容声明更新可见。重复快照保留原行与选择。
- AC-02 由本地库测试和下载合并刷新测试覆盖。删除后的旧扫描不能恢复条目，配置文件读取失败不影响下载触发的本地扫描。
- AC-03 由桌面测试使用临时安装文件覆盖删除、重启和重新安装。已卸载时保留历史和重新下载入口，隐藏打开目录。另有单元测试核对同工坊 ID 的另一副本。
- AC-04 由本地库测试核对工坊目录范围。真实 Steam 账户和监狱建筑师旧容器未联调。
- 回归过程中修复取消回调尚未结束时释放句柄的问题。原句柄回归连续执行 20 次全部通过。

2026-11-07 在 macOS arm64 执行以下检查。Release 构建通过，572 项测试通过。已核对删除后下载卡片的无窗口截图。

```shell
dotnet restore SteamModManager.sln
dotnet build SteamModManager.sln --configuration Release --no-restore
dotnet test --solution SteamModManager.sln --configuration Release --no-build
git diff --check
```
