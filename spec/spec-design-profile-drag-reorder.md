# 背景与目标

用户可以从行首拖动 Mod 到目标位置，减少跨多行排序的重复操作。

## 1. 范围与非目标

运行配置的同一份清单。保留上下移动按钮、草稿、保存与应用流程。

## 2. 需求与验收条件

| ID | 给定 | 当 | 则 |
| --- | --- | --- | --- |
| AC-01 | 可编辑的 Mod 列表 | 拖动行首手柄到另一行上半或下半后松开 | 提示插入位置，移动一次，选中原条目并重新编号 |
| AC-02 | 拖动中 | 取消、移出清单后释放、切换配置或工作区 | 不改动任何配置 |
| AC-03 | 清单超过可视范围 | 拖近边缘 | 列表滚动，可跨多行插入，保存及启动器顺序遵循新序 |

## 3. 责任模块与实现步骤

MainWindow 管理指针、捕获、插入指示和边缘滚动，视图模型统一执行重排并刷新草稿。文件、配置格式、启动器写入点均沿用现状。

## 4. 契约、依赖与兼容性

沿用 Avalonia 指针事件与当前集合，不引入依赖或持久化字段。

## 5. 测试策略

桌面无窗口夹具执行按下、拖动和松开，并测试取消、双方向和保存。门禁见 [协作规范](../CONTRIBUTING.md#4-必须完成的检查)。

## 6. 审查与执行结果

AC-01 至 AC-03 通过。桌面使用实际指针事件验证上下跨行、插入线、Escape 和释放在列表外、18 行清单边缘滚动、保存后顺序及重新编号。工作区切换取消捕获，配置切换后旧行对象无法用于移动。按钮与拖拽共用重排和草稿流程，既有启动器应用回归通过。

macOS arm64 执行解决方案还原、Release 构建、595 项全量测试及 `git diff --check`。无窗口截图和测试报告保存在本地 `artifacts/batch1/`。
