# 背景与目标

本地副本可能保留工坊 ID。标签、批量更新和删除需要共用安装管理分类。

## 1. 范围与验收

| ID | 给定 | 当 | 则 |
| --- | --- | --- | --- |
| AC-01 | 本地副本与 Steam 安装具有相同工坊 ID | 扫描 | 保留共同工坊来源和各自安装 ID。只有 Steam 管理的安装显示「STEAM」。 |
| AC-02 | 配置中存在本地副本、Steam 安装或旧版应用自管安装 | 检查工坊更新 | 只查询可用且启用的 Steam 安装。 |
| AC-03 | 删除已确认的安装 | 核对路径并执行 | 本地副本不退订，Steam 安装先退订，旧版自管安装使用原物品锁。外部和越界位置保持拒绝。 |

## 2. 责任模块与契约

Infrastructure 依据扫描环境与已安装位置做分类。删除前复用规则并保留原有安全检查。Application 与 Desktop 消费同一分类。安装 ID、工坊 ID、旧配置和对外 JSON 格式沿用现有契约。

## 3. 测试与结果

- 本地目录及压缩包保留工坊 ID 并归类为本地。删除测试验证不调用 Steam 退订，Steam 目录先退订再删，外部位置和符号链接保留防护。
- 批量更新夹具验证只查询启用且可用的 Steam 安装，应用自管与本地副本不进入查询。下载与删除链路覆盖旧版自管安装。
- macOS arm64 按[协作规范](../CONTRIBUTING.md#4-必须完成的检查)执行还原、Release 构建、完整测试和差异检查。575 项测试通过。
