# 背景与目标

用户选择一个离线 Mod，预览名称、声明版本和安装目录，确认后直接在本地库使用。

## 1. 范围与非目标

仅 CK3。支持根目录或唯一一级子目录包含 descriptor.mod 的 ZIP／文件夹。沿用当前 Mod 库、配置和本地删除。

## 2. 需求与验收条件

| ID | 给定 | 当 | 则 |
| --- | --- | --- | --- |
| AC-01 | 有效单 Mod 文件夹或 ZIP | 预览后确认 | 复制到 CK3 本地目录，生成受控外层描述文件并重新扫描 |
| AC-02 | 路径穿越、链接、重复或大小超限 | 读取来源 | 拒绝并保留已有安装 |
| AC-03 | 来源变化、取消或并发同目标 | 安装 | 重核预览与来源，失败清理暂存，已存在目标不覆盖 |

## 3. 责任模块与实现步骤

Core 提供安装端口。Infrastructure 校验输入、暂存并发布。Application 重新发现目标和刷新本地扫描，Desktop 选择文件并确认。ZIP 路径与资源约束同快照包复用。

## 4. 契约、依赖与兼容性

现有 CK3 描述格式和安装 ID 保持兼容。来源描述中的工坊 ID 作为声明，安装由本地管理。包大小与路径约束在实现中明确。

## 5. 测试策略

临时目录与 ZIP 验证有效、畸形、并发、取消、重试和本地删除。按 [协作规范](../CONTRIBUTING.md#4-必须完成的检查) 执行门禁。

## 6. 审查与执行结果

AC-01 至 AC-03 通过。ZIP 和文件夹均可预览、安装并被本地扫描识别。验证工坊声明 ID 的本地副本可通过现有入口删除，无退订。测试覆盖绝对路径、越界路径、同路径及大小写别名、文件目录冲突、保留名、符号链接、包目录歧义、来源变化、取消、并发同目标和重试。ZIP 最多 50 万条路径和 64 GiB 解压内容，单描述文件最大 1 MiB。

macOS arm64 执行还原、Release 构建、619 项全量测试和差异检查。截图和证据在本地 `artifacts/batch3/`。
