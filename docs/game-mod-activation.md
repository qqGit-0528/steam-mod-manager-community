# 启用、禁用与播放集应用

本地 Mod 库和运行配置页都有带电源符号的开关，编辑同一份选中配置。红色或当前游戏强调色表示启用，灰色表示禁用。禁用会保留条目和加载位置；配置页可上移、下移或移除。尚未添加到配置的本地 Mod，启用时会自动加入。

“保存配置”只保存本工具的清单。“应用到游戏”将启停和顺序写入官方启动器的独立本地播放集；“启动游戏”会先应用待处理改动，失败时停止启动。游戏和官方启动器应先退出，以免其内存中的旧配置覆盖新数据。启动器尚未初始化数据库时，需要先打开一次让其发现游戏与 Mod。

没有本地保存的配置时，工具会读取当前官方播放集，带入启停和顺序；已有保存配置时会核对当前官方配置是否一致。“读取游戏配置”另建一份草稿，保留原草稿。官方数据库中同一安装内容的重复行在导入时合并，保留任一启用状态和第一次出现的位置。

## 为什么不只改 dlc_load.json

P 社启动器保存播放集与 Mod 关联，再按游戏启动协议生成加载文件。只改派生 JSON，之后使用官方启动器启动时可能被重新生成的内容覆盖。

本机安装的 Launcher 2026.13 和游戏配置给出了以下区别：

| 游戏与已检查版本 | 启动器 formatVersion | 派生加载文件 | 启用项格式 |
| --- | --- | --- | --- |
| CK3 1.20.0.4 | 0 | `dlc_load.json` | `enabled_mods`，有序的外层 `.mod` 相对路径 |
| Victoria 3 1.13.11 | 1.1 | `content_load.json` | `enabledMods`，含 `path` 的目录或压缩包对象 |

实现读取 `launcher-settings.json` 的实际 `gameId` 与 `formatVersion`，不根据中文游戏名推测格式。只接受已适配的 0 和 1.1；未知格式、缺少必需列或错误游戏目录会明确拒绝。监狱建筑师不使用这套播放集，按钮保持不可用。

## 写入范围与恢复

- `mods`：复用指向同一真实内容的原登记项；新 `.mod` 内容在需要时生成用户 Mod 目录下的外层描述，保留声明字段并使用真实工坊身份。新登记的 metadata 本地目录必须位于官方 `modPath` 的直接子目录。尚未登记的外部 metadata 路径会拒绝应用，避免被官方启动同步判定缺失；已有官方登记的 Steam Mod 可直接复用。
- `playsets`：根据当前游戏与本工具配置 ID 生成稳定标识，以 `Mod Manager · ` 为名称前缀。使用私有本地播放集，拒绝覆盖其他名称、共享或受管理的同标识播放集。
- `playsets_mods`：只重建本工具播放集的关联、`enabled`、从零开始的 `position`，使用 `custom` 加载顺序。禁用项保留位置，但官方导出会过滤禁用或未就绪项。
- `playsets_dlcs`：继承应用前活动播放集的 DLC 开关，不改变 DLC 所有权。原播放集的内容、Mod 关联和 DLC 选择均保留；活动标记切换到本工具播放集。

写入前使用 SQLite 在线备份，包含已提交的 WAL 内容。备份在本游戏的工具数据目录 `activation-backups/`，创建新备份前裁剪为四份，再增加本次备份，成功和失败都最多五份。事务失败或提交前取消时回滚数据库，并清理本次新建的 wrapper。不会自动以旧备份覆盖用户后来的数据库改动；如需恢复，先退出官方启动器和游戏，再备份当前数据库后恢复所选副本及 SQLite 日志文件的一致状态。

原播放集仍保留在 P 社启动器里，也可直接切回。SQLite 写入前后都检查启动器/游戏进程，工具实例之间使用文件锁。外部进程启动与检测存在操作系统调度窗口，因此应用时应保持启动器关闭。

## 支持与验证范围

已用当前生产代码处理本机两款游戏的数据库副本：交换启停、反转顺序、事务提交及回读一致；原数据库哈希保持不变。CK3 处理 5 个活动条目，Victoria 3 的原始 10 条关联含重复内容，导入后为 9 个独立条目。再隔离执行本机启动器原始导出映射，分别生成 4 条 `enabled_mods` 和 7 条 `enabledMods` 路径对象，顺序与应用结果一致。未运行完整游戏，未声称存档或 Mod 实际玩法兼容。

自动化另覆盖两页开关与保存/应用区别、待应用配置启动门控、重复应用不重复创建播放集、原播放集与 DLC 保留、旧 JSON 默认启用、错误目录/未知数据库结构拒绝、启动器中途打开回滚、失败备份上限、wrapper 工坊身份及 metadata 坏根隔离。

HOI4、EU4、Stellaris、Imperator 在检测到受支持协议后使用同一适配器，尚未做对应游戏实机联调。1.1 官方导出将目录组放在压缩包组前，目前拒绝启用两种格式混排，以免改变用户指定顺序。metadata 支持不代表下载器已验证该游戏所有打包形式。
