# Steam Mod Manager 规格驱动开发

1. 从仓库的 `AGENTS.md` 进入架构约定和仓库导航。先定位实际入口、现有责任模块 和测试，再决定修改位置。
2. 从 `spec/TEMPLATE.md` 起草或更新本次软件规格。确认目标、非目标、可观察结果及失败时的状态。下载任务移除与已安装内容删除分别验收。
3. 实现前记录改动涉及哪一层、哪个责任模块、是否产生第二份状态或写入路径、哪些调用方会受影响。沿现有入口实现。确需扩展边界时更新同一份规格，并按 `AGENTS.md` 确认影响。
4. 对照规格 审查差异。Steam 与文件操作同时检查身份、路径、锁、失败与重试，核对真实副作用。验证夹具使用临时文件或替身。
5. 按 `CONTRIBUTING.md` 运行相应检查，将验收条件、实际命令、结果和未验证场景回填到同一份规格。PR 引用这份记录。
